# 关于熊

你好，我是熊，一名正在学习 AI 和 GitHub 开源项目的体外诊断试剂研发工程师。

这个博客目前用来记录我对 AI 工具、开源项目、工程化工作流和个人知识管理的学习过程。这里不会只放最终结论，也会保留一些阅读、拆解、试错和复盘的痕迹。

## 我在关注什么

- AI Agent、插件系统和工具调用机制
- GitHub 开源项目的源码阅读与部署实践
- 体外诊断试剂研发工作中的自动化、文档化和知识管理
- 把零散学习记录整理成可复用的项目笔记

## 为什么写这个站

学习新工具时，最容易丢失的是过程：当时为什么这么理解、踩过什么坑、哪些概念后来串起来了。

所以这个站更像一个公开的学习日志。我希望它既能帮自己回看，也能让朋友快速了解某个项目是否值得继续研究。
