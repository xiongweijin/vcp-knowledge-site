## 三、通用优化清单

以下 4 项适用于所有 Agent，按优先级排列：

### ⭐⭐⭐ 必须检查

1. **`{{VCPTavern::dailychat}}`**：凡是被小娜团队调度表列出的 Agent（小克、小绝、小程、小雨、教员），都应确认此行存在。当前小程缺失。

2. **`<<VCP开发日记本>>`**：凡是需要理解 VCP 源码的 Agent（小克、小绝、小程），都应有此行。当前仅小娜、小绝有。

### ⭐⭐ 建议优化

3. **记忆参数审查**：当前 6 个 Agent 的记忆参数几乎完全一致（`TagMemo0.65/0.5/0.55`）。但不同角色对记忆召回的需求不同：
   - 创意型（小雨、小绝）→ 知识日记本阈值降低到 0.35-0.4（更广联想）
   - 精确型（小克）→ 保持 0.5（精准召回）
   - 管理型（小娜）→ 保持 0.5（平衡）

4. **`</thinking>` 闭合标签策略一致化**：
   - 教员/小娜 → 显式写 `</thinking>`（「以 `</thinking>` 闭合后再正式回复」）
   - 小程 → 表述有歧义
   - 小克 → 显式写了闭合标签
   - **建议统一**：要么全部依赖 LLM 自动推断（不写闭合标签），要么全部显式写。混用可能导致不同 Agent 在不同模型上表现不一致。

## 五、关键提醒

1. Agent 提示词修改后，`agent_map.json` 对应的文件会自动热重载（`agentManager.js` 使用 chokidar 监听），无需重启服务器。

2. 修改记忆参数（`TagMemo` 阈值）立即生效——`RAGDiaryPlugin` 在每次消息预处理时读取最新参数。

3. 添加新的 `{{VCPXxxToolBox}}` 占位符前，确认该 toolbox 已在 `toolbox_map.json` 中注册。

4. 修改后的提示词建议在至少 2 个模型上验证（按 `思维链配置说明.md` 的建议：Claude + Kimi）。
