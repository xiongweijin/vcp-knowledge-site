    主街道

    请求进入城门，经过翻译局和档案馆，交给模型，再根据是否有工具单决定是否回路。

    档案馆

    长期知识、标签联想、附件召回、上下文折叠都在这里，不是模型凭空记住。

    工具行会

    工具不是提示词附属品，而是有 manifest、审批、执行、返回和分布式上下线的机构。

    市政系统

    配置、日志、审批、AdminPanel、WebSocket 决定城市能否稳定、安全地运行。

    三条学习路线

    使用者路线

    城门 -> 翻译局 -> 智能货架 -> 档案馆。先掌握 Agent、DynamicTools、RAG 和工具块。

    造工具路线

    工具单识别 -> 工具单执行 -> 行会总管 -> 工具窗口。重点看 manifest、参数、审批和返回格式。

    维护者路线

    总调度室 -> 翻译局 -> 档案馆 -> 行会总管 -> 市政厅。按链路定位故障，不要直接猜插件问题。

    分布式路线

    行会总管 -> 城际总站 -> 远程分馆 -> 物流回源。关注 VCP_Key、register_tools、tool_result 和 file://。
